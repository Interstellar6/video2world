# Bedroom4 pillow attempt-2 input evidence

These files preserve the first deterministic amodal-RGBA preparation experiment. They are
not generation-ready inputs. See `batch_generation_decision.json`: the batch is
`rejected_before_generation` until each physical pillow is revalidated from at least two
original-video frames with per-frame masks and an explicit identity decision.

The rear pillows may genuinely contain pale gray-green patchwork and brown floral details.
The rejection therefore records insufficient single-frame identity/color evidence, not a
confirmed background-contamination diagnosis.
