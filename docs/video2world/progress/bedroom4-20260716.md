## Pillow delta

fresh 没有独立 pillow，旧标签又混入 bed，因此新 run 隔离执行，不覆盖权威目录。

| 尝试 | 点数/配置 | 三视角最低命中 | 结论 |
|---|---|---:|---|
| raw | 262,390 points | 0.8796 | failed：混入床头板 |
| top3 + score>=0.90 | 245,747 main points | 0.918 | failed：仍低于 0.95 |
| + erosion5 + rel-depth0.005 + min-votes2 | 209,479 points | 0.9734 | passed |

accepted ID 是 `sam3_pillow_01`，代表三个相触枕头的 ensemble。AABB center `[-1.45619, -0.51465, 15.30182]`，extent `[7.26258, 3.19008, 4.07937]`，PLY SHA-256 `7590a8d9...017a1452`。

accepted cloud 的三视角命中率分别是 `0.9818 / 0.9863 / 0.9734`，全部通过 `>=0.95` 门禁。

允许：scene query、相机 focus、bbox highlight、point-cloud visual rotation。未允许：独立 pillow mesh/GLB、机器人碰撞、软体物理、把三个枕头当作稳定单实例。

## EmbodiedGen V2 资产

归档包含 9 个 Gaussian PLY 与 9 组 GLB/OBJ。首批 Web 替换对象为 nightstand 01/02、plant 01/02；door 01/02 因类别输出接近 cabinet 而拒绝。所有原始 GLB 非 watertight，必须经 collider simplification 与场景 placement QA。

| 对象 | Gaussian vertices | GLB faces | 当前判断 |
|---|---:|---:|---|
| nightstand 01 | 733,856 | 315,438 | usable candidate |
| nightstand 02 | 726,289 | 284,494 | usable candidate |
| plant 01 | 1,281,643 | 30,750 | low-poly fallback candidate |
| plant 02 | 710,528 | 736,038 | low-evidence proxy candidate |

Gaussian 和 GLB 是同一 RGBA/seed 的两次 decoder 输出，不是从 final Gaussian PLY 转换得到；二者需分别记录 hash。auto-completion 实际引用 2026-07-13 的较早 Holi run，不是 07-14 fresh；二者实例集合不同，绑定必须包含 scene run、object ID、source hash 与 alignment report。

## Qwen 场景描述

本地推理使用 `Qwen/Qwen2.5-VL-3B-Instruct`，精确 revision `66285546d2b821cf421d4f5eb2576359d3770cd3`，并以 `local_files_only=true` 校验权重。模型是 3,754,622,976 parameters；两片 safetensors 的 index 总量为 7,509,245,952 bytes。运行栈是 `transformers 4.57.3`、`torch 2.5.1+cu124`、`bfloat16`、SDPA、NVIDIA RTX 3090；加载记录中 missing、unexpected、mismatched keys 与 errors 均为空。

6/6 个对象描述通过。每条结果保留精确 model revision、prompt/raw-output hash、输入图与 frame/mask evidence。最终 provider 为 `local_huggingface_transformers+agent_visual_audit`：Qwen 初稿之后经过确定性 schema 规范化和逐图审计修正，因此文档同时保留原始模型输出与最终 reviewed description，不把二者混为一谈。
